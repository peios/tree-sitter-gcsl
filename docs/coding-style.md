# Coding style

Follow Panorama PSC for maintained C, JavaScript, Python, and shell. Use four spaces and the strong 100-column target. Keep Tree-sitter
node names, capture names, scanner entry points, and external-token order:
these are editor and generator contracts.

`src/parser.c`, `src/grammar.json`, `src/node-types.json`, and
`src/tree_sitter/` are generated by pinned Tree-sitter 0.27.1. Regenerate
them with `tools/generate` rather than formatting them. The Wasm compiler, optimizer, and test runtime are pinned upstream inputs,
not maintained copies of this project's code.

The grammar's rule tables and expression variants exceed PSC's soft
function-length threshold. Keeping each declarative rule family together
makes precedence and aliases easier to review. Review handwritten scanner
branches separately; table size is not a reason to waive control-flow
review.
